# Propuesta de Desarrollo — Motos El Zarco

Esta carpeta contiene la presentación web interactiva de la propuesta comercial y técnica para **Motos El Zarco**, diseñada con la identidad visual corporativa de **Hero MotoCorp** (Rojo Hero `#D9121E`, Negro y Blanco).

## Estructura de Archivos

- `index.html`: Página principal interactiva con navegación, presentación del sistema, módulos, vistas previas, flujo de procesos, arquitectura técnica, cronograma por fases, inversión y beneficios.
- `styles.css`: Hoja de estilos moderna y responsive adaptada a la paleta de colores de Motos El Zarco / Hero.
- `preview-interfaces/`:
  - `ventas-pos.html`: Mockup interactivo del Punto de Venta (POS) con búsqueda, códigos QR y panel de cobro.
  - `inventario.html`: Mockup interactivo de control de existencias, repuestos, marcas y catálogo.
  - `finanzas.html`: Mockup interactivo de caja, ingresos, gastos y márgenes de utilidad.

## Cómo visualizar la propuesta

Simplemente abre el archivo `index.html` en tu navegador web favorito (Chrome, Safari, Edge) o levántalo con un servidor local (`npx serve .` o Live Server).
